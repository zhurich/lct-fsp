# Описание API

Все методы начинаются с `/api`, принимают и возвращают JSON (кроме загрузки резюме и выгрузки PDF). Авторизация — cookie `access_token`, которую выставляет метод входа. Общие коды ошибок: 401 — не выполнен вход, 403 — раздел другой роли, 422 — ошибка в данных запроса (текст — в поле `detail`). Полные схемы запросов и ответов — в интерактивном описании `/api/docs` и в `/api/openapi.json`.

### Авторизация

| Метод и путь | Назначение | Свои коды ошибок |
|---|---|---|
| `POST /api/auth/register` | Регистрация по электронной почте | 409 — Почта уже зарегистрирована; 503 — Не удалось отправить письмо; учётная запись не создана |
| `POST /api/auth/verify` | Подтверждение адреса почты по токену из письма | 400 — Ссылка недействительна или устарела |
| `POST /api/auth/resend-verification` | Повторная отправка письма (не чаще раза в минуту на адрес) | 429 — Слишком много запросов |
| `POST /api/auth/login` | Вход; токен доступа выдаётся в httpOnly-cookie | 401 — Неверная почта или пароль; 403 — Почта не подтверждена; 429 — Слишком много запросов |
| `POST /api/auth/logout` | Выход: сессия закрывается на сервере | — |
| `GET /api/auth/me` | Текущий пользователь | — |
| `DELETE /api/auth/me` | Отозвать согласие: удалить учётную запись и все связанные данные | — |
